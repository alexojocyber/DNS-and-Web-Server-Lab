# DNS and Web Server Lab

## Objective

Configure a DNS server and a web server in Cisco Packet Tracer and verify that clients can access the website using a domain name.

## Topology

- Router0: 192.168.10.1
- DNS Server: 192.168.10.2
- Web Server: 192.168.10.3
- PC0: 192.168.10.10

## DNS Record

Name: company.local

Address: 192.168.10.3

## Verification

- Ping tests successful
- DNS resolution successful
- Website accessible through `http://company.local`# DNS-and-Web-Server-Lab
